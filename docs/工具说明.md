# 工具说明（给用它的模型看）

`dsh-dexter` 只暴露 **4 个工具**。它们是一个整体：看 → 动 → 批量 → 查。
所有写动作都着落在同一道闸门上；所有动作都写进同一条审计。

---

## `hands_view` —— 看（只读，不需要授权）

| 动作 | 作用 | 典型参数 |
|---|---|---|
| `info` | 显示器、光标、前台窗口、引擎状态 | 无 |
| `list` | 列窗口 | `query`（过滤）、`limit` |
| `capture` | 截图（可整屏 / 窗口 / 区域） | `window`、`region` |
| `zoom` | 放大细节（1..8 倍） | `x`/`y` 或 `region`、`scale` |
| `locate` | 屏幕 ↔ 图像坐标换算 | `x`/`y` 或 `fx`/`fy` |
| `text` | 读窗口里的文字元素（UIA） | `window`、`limit` |
| `read` | 自动读屏（text-first，必要时退截图） | `window`、`limit` |
| `uia` | 控件树；给 `path` 只回位置/顺手点击用 | `window`、`query`、`path` |
| `wait` | 等画面稳定 | `region`、`timeoutMs` |
| `wait_window` | 等窗口出现 | `window:{titleContains\|pid\|handle}`、`timeoutMs` |
| `focus` | 切前台（**会改前台**，有审计） | `window` |

**先看再动**：坐标类写动作要求 **120 秒内**有一次观察，否则会被拒绝（"观察新鲜度"）。

## `hands_act` —— 动（写，走闸门）

`action` 取值：`move` / `click` / `drag` / `scroll` / `type` / `key` / `hotkey` / `clipboard_get` / `clipboard_set` / `stop`

- `move`：**悬停免授权**（留痕、限速；鼠标键按住时拒绝——那等于拖拽）；
- `click` / `drag` / `scroll` / `type` / `key` / `hotkey`：需要授权（会话或逐条请示）；
- `clipboard_*`：**永远逐条请示**，会话授权不覆盖；
- `stop`：撤销授权（只收不放）。

目标写法（三选一）：

| 写法 | 例子 | 说明 |
|---|---|---|
| 绝对坐标 | `x: 942, y: 1020` | 物理像素 |
| 窗口相对 | `window:{pid:123}, fx:0.5, fy:0.5` | 窗口内归一化 |
| UIA 控件 | `control: "0/2/1"` | 动作时**重测位置**；`how: invoke\|click` |

其他参数：

- `dryRun: true` —— 只解析目标与授权，**不注入、不消耗授权**（先预演是好习惯）；
- `expect: { process: "notepad.exe", titleContains: "..." }` —— 执行后做前台断言，结果写进审计；
- `count`（连击）、`button`、`toX`/`toY`（拖拽终点）、`deltaX`/`deltaY`（滚动）。

⚠️ 两个必须知道的：
- `type` 只保证"已发送"，**要确认就 `hands_view { action:'read' }` 或读回文件**；
- **Esc 不能注入**（它是急停通道，会被拒）。要关菜单请点别处。

## `hands_run` —— 批量（一次授权，按步扣费）

```json
{"steps":[
  {"action":"move","window":{"pid":123},"fx":0.5,"fy":0.2},
  {"action":"click","window":{"pid":123},"fx":0.5,"fy":0.2},
  {"action":"type","window":{"pid":123},"text":"hello"},
  {"action":"hotkey","window":{"pid":123},"keys":"ctrl+s"}
]}
```

- 一次决策覆盖整批，但**按步扣额度与频率**（25 步要 25 次额度）；
- 余额不足 → **整批拒绝**（不会跑一半）；
- 某步失败默认停住，并给 `resumeFrom` 续跑点；`stopOnError:false` 可继续；
- 每步都复查：停止信号 / 人类活动 / 观察新鲜度。

## `hands_status` —— 查（只读）

状态里写清楚"下一次写动作会不会被拒"：

- 授权余量、到期时间、急停状态、人类是否在操作；
- 后端可用性（`pixel=ok · uia=ok`）、热键由谁持有、面板是否在跑；
- 配置摘要（时长/次数/频率/验证方式/图片预算）；
- `doctor: true` 追加引擎自检（截图、热键、授权状态）；
- `tail: N` 附最近 N 条审计。

## 命令与界面

| 入口 | 用法 |
|---|---|
| `/dexter arm [45m] [300]` | 开授权（不带数字 = 用设置里的值） |
| `/dexter extend [分钟] [次数]` | 续期 |
| `/dexter stop` / `/dexter clear` | 急停 / 解除急停标记 |
| `/dexter set <键> <值>` | 改持久配置（如 `set askOnWrite false`） |
| `/dexter status [doctor] [tail N]` | 同 `hands_status` |
| `/dexter panel show\|hide\|reset\|exit` | 面板 |
| 输入框旁「授权」「面板」 | 两个按钮（授权 = `/dexter arm`） |
| 桌面右上角面板条 | 状态 + 右键「设置」加减时长/次数/频率 |
| 热键 | `Ctrl+Alt+F12` 授权 · `F10` 续期 · `Shift+F11` 软停 · `F11`/`Esc` 急停 |

## 一次完整操作长什么样

```text
hands_status                          # 有没有授权、后端在不在
hands_view { action: 'info' }         # 屏、光标、前台窗口
hands_view { action: 'list', query: '记事本' }   # 找窗口
hands_view { action: 'uia', window: {...} }    # 取控件路径
hands_act { action: 'click', control: '0/2/1', dryRun: true }   # 预演
hands_act { action: 'click', control: '0/2/1' }                 # 真点
hands_act { action: 'type', text: '...' }                       # 打字
hands_view { action: 'read' }         # 读回确认
```

## 会被拒绝的情况（不是 bug）

- 没有授权、且逐条请示被拒；
- 目标属于系统/安全类（注册表、任务管理器、安全软件、凭据管理器、管理员窗口）——**永久**；
- 目标属于私人类（聊天/邮件/支付/密码）——即使有会话也逐条问；
- 120 秒内没看过屏（坐标类写动作）；
- 人类正在操作（会暂停，空闲 20 秒后恢复）；
- 急停状态未解除（`/dexter clear`）；
- 注入 Esc（急停通道）。
