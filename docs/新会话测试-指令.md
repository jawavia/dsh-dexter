# 新会话验收指令（复制粘贴用）

> 用途：在一个**全新的 DSH 会话**里验收 `dsh-dexter`。只验收，不改代码、不改配置、不推送。
> 用户需要配合的动作只有两个：开一次授权（`Ctrl+Alt+F12` 或点输入框旁「授权」），以及必要时右键面板点两下。

---

## 粘贴给新会话的第一段

```text
这个会话只做一件事：验收已装好并启用的 DSH 插件 dsh-dexter（桌面操作）。
它给我的工具是 hands_view / hands_act / hands_run / hands_status 四个。
规则：
1. 不改仓库代码、不改配置、不 push、不发布；只读 + 真机验证 + 报告。
2. 每一步都要给证据（命令输出、审计行、文件字节），不要写"应该没问题"。
3. 真机注入需要一次会话授权：如果你发现没有授权，停下来告诉我"请按 Ctrl+Alt+F12 或点授权按钮"，我等你说继续。
4. 发现任何失败，原样贴错误，不要自己改代码重试；先报告，等我决定。

按这个顺序做：
A. 只读基线：hands_status（看后端/面板/审计/授权）、hands_view info、hands_view list limit=10。
B. 截图：hands_view capture region={x:2200,y:60,w:640,h:220}（右上角，应能看到面板条），确认返回坐标映射。
C. 预演：hands_act { action:'click', x:640, y:520, dryRun:true } ——只解析目标与授权，不注入。
D. 真注入（需要授权）：
   1) 先 Shell 开一个记事本（不要用工具里的 spawn，会被判为目标进程不安全）：
      powershell: $f="$env:TEMP\dexter-new-<时间戳>.txt"; Set-Content $f "seed"; (New-Object -ComObject Shell.Application).ShellExecute("notepad.exe","`"$f`"","","open",1)
   2) hands_view { action:'wait_window', window:{titleContains:'dexter-new-'}, timeoutMs:8000 }，把返回的 pid 记下来
   3) hands_act { action:'type', window:{pid:<pid>}, text:'new-session-<时间戳>' }
   4) hands_act { action:'hotkey', window:{pid:<pid>}, keys:'ctrl+s' }
   5) 命令行读回：Get-Content 那个文件，确认内容 = 你打的字 + seed（顺序按光标位置，可能在前）
   6) 关掉记事本：Stop-Process -Name notepad -Force
E. 批量：hands_run { steps:[ {action:'move', x:640, y:520}, {action:'move', x:700, y:560} ], dryRun:true }，
   然后再跑一次不带 dryRun 的（两个 move 是悬停，不消耗授权）。
F. 面板改数字（这一步不需要授权，但需要我右键面板点两下，或你自己用命令行模拟）：
   写 %USERPROFILE%\.dsh\dexter\panel-requests.txt 内容 "cfg armMinutes +5"，等 3 秒，
   检查三处：state.txt 第三行、runtime-overrides.json、审计里 tool=panel 的 set 行；
   再写 "cfg armMinutes -5" 复原。
G. 审计与套件：
   node tools/audit-stats.mjs
   node test/run-all.mjs      （期望 12/12）
   node tools/check-repo.mjs  （期望 0 FAIL 0 WARN）
H. 报告格式：
   - 每条链路：通过 / 失败 / 未验证（写明为什么）
   - 消耗了多少次授权（审计里 session 计数）
   - 审计是否新增断链（逐行校验 prev === 上一行 h，历史上 2026-11-14 15:00 前有 4 处已知断裂）
   - 发现的问题按"阻塞/一般/建议"分级，附原样错误
```

---

## 用户要配合的两件事

1. **授权**：`Ctrl+Alt+F12`（15 分钟 / 100 次），或点输入框旁「授权」按钮，或输入 `/dexter arm`。
   到期后新会话再要授权会说"没有授权"，按一次即可。
2. **面板**（可选）：右键桌面右上角那条 → 「设置」里点几下加减，看数值是否当场变。

## 工具速查（新会话的 agent 看这一节就够）

| 工具 | 关键参数 | 用在哪 |
|---|---|---|
| `hands_status` | `doctor:true`、`tail:N` | 开局面：后端、面板、热键、授权余量、审计尾 |
| `hands_view` | `action: info / list / capture / text / read / uia / wait / wait_window / focus / zoom / locate` | 读：不注入、不受授权约束（截图受图片预算） |
| `hands_act` | `action: click / drag / scroll / move / type / key / hotkey / clipboard_* / stop`；`dryRun` 只预演；`expect` 做前台断言 | 单步写动作 |
| `hands_run` | `steps[]`（≤25）、`dryRun`、`stopOnError`、`resumeFrom` | 一串动作，一次授权，按步扣额度 |

要点：
- **写动作先看一眼**（观察新鲜度 120 秒内），否则会被拒绝；
- 目标用 `window:{pid}` 最稳，`titleContains` 次之；
- `type` 只保证"已发送"，**要确认就 `hands_view { action:'read' }` 或读回文件**；
- 客户端程序（浏览器/记事本）优先 UIA（`hands_view text` 拿元素坐标），不要靠猜像素。


## 判定标准

| 项 | 通过条件 |
|---|---|
| 只读 | info/list/capture 都返回结构化结果，坐标映射自洽 |
| 授权 | 无授权时 dryRun 能跑、真写被拒并给出"怎么授权" |
| 真注入 | 文本落盘，字节与打的字一致（含编码） |
| 批量 | dryRun 不注入；真跑按步扣额度；失败给 resumeFrom |
| 面板 | 加减后 3 秒内 state 第三行 + overrides 文件 + 审计三处一致 |
| 审计 | 无新增断链；行数增加；`prev === 上一行 h` |
| 套件 | 12/12；check-repo 0 FAIL 0 WARN |

## 已知限制（不要当 bug 报）

- 授权到期后所有写动作都会被拒（这是设计）；
- 系统/安全类目标永久禁止（注册表、任务管理器、杀软、凭据管理器、管理员窗口）；
- 聊天/邮件/支付/密码类目标即使有授权也逐条请示；
- 读不受闸门约束（这是已声明的取舍）；
- 目标识别是"进程名 + 标题子串"，改名程序可能漏判；
- 插件重载前的 4 处审计断链是历史，不追改（审计只追加）。
