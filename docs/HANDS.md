# 桌面操作手册（晶格工作流 / 成本 / 何时用哪个目标）

这是给模型看的操作手册。它是**按需文档**：工具描述里只有一行指针，不看就不占上下文。

## 1. 先看再动

1. `hands_view { action: 'read' }` —— text-first：先拿 UIA 元素（有 `中心=` 坐标，可直接点）。
2. 元素不够（画布、游戏、自绘界面）→ `hands_view { action: 'capture', region: {...} }` 拿图，
   图上有晶格线与坐标映射（`屏幕x = origin.x + fx*宽`）。
3. 坐标类写动作要求 **120 秒内**看过屏（可配置）；否则先看一眼。

## 2. 三种目标，优先级从上到下

| 目标 | 参数 | 什么时候用 |
|---|---|---|
| UIA 控件 | `control: '0/2/1'`（来自 read/uia 的路径） | 首选：动作时**重新量位置**，布局漂移也不怕；按钮直接 Invoke，输入框直接赋值，不碰鼠标键盘 |
| 窗口相对坐标 | `window: { handle }` + `fx`/`fy`（0..1） | 窗口会移动/缩放时用它，比绝对坐标稳 |
| 绝对坐标 | `x`/`y`（物理像素） | 最后手段；换分辨率/缩放后会失效 |

`hands_view { action: 'uia', path: '0/2/1' }` 可以先把控件位置量出来再决定。

## 3. 晶格（只有像素路径才有）

`capture` 的输出会给出：当前晶格档位、屏幕间距、原点、每格的换算公式。用法：

1. 图上看清目标落在哪一格（或哪两格之间）；
2. 用 `hands_view { action: 'locate', x, y }` 把任意屏幕点换算回晶格/图像坐标；
3. 点击用**绝对坐标**（`x`,`y`）或窗口相对（`window`+`fx`/`fy`），不要传格子编号——
   新插件不认旧引擎的 `grid:"C3"` 语法，请直接给点。

## 4. 成本控制（每张图都花钱）

- 截图是最大开销：先用 `read`（≈1.2k tokens），不够再 `capture`（按图大小计价，预算默认 12 张/8k tokens 每 120 秒）；
- 只看需要的那一块：`region` 永远比全屏便宜；
- 连续操作不要每步截图：`hands_run` 一步一审计，最后再 `read` 一次验证；
- `capture` 会做画面去重：画面没变时不重复出图，你会看到"画面未变化"。

## 5. dryRun / 验证

- 不确定会打到哪：`hands_act { ..., dryRun: true }` —— 解析目标、报告会不会被拒，**不注入、不消耗授权**。
- 真执行后会按配置验证：`verifyMode=foreground` 用 `expect:{process|titleContains}` 断言前台；
  `hash` 比较目标区域画面是否变化。验证结果是工具返回里的 `验证：…` 行。

## 6. 什么时候会被拒（先自己判断，别硬试）

| 情况 | 结果 |
|---|---|
| 系统/安全类目标（注册表、任务管理器、安全软件、凭据管理器、系统设置、管理员窗口） | **永久拒绝**，任何授权都不覆盖 |
| 聊天 / 邮件 / 支付 / 标题像密码或 `.kdbx` 的目标 | 即使开了会话也**逐条请示** |
| 人类正在用鼠标键盘 | 暂停/等待（默认等 20s 空闲）；被拒就等一会儿再试 |
| 没有会话授权 | 每次点击问一次；`/dexter arm 15m 100` 或 `Ctrl+Alt+F12` 开一次 |
| 超过频率上限（默认 30/分） | 拒绝并告诉你要等几秒；批量任务先调高 `maxActionsPerMinute` |
| 急停之后（Esc / Ctrl+Alt+F11 / stop） | 一律拒绝，直到人手重新授权 |

## 7. 一次做多步

`hands_run { steps: [...] }`：整批只问一次授权、每步一行审计、失败给你 `resumeFrom` 续跑点；
`dryRun: true` 可以整批预演。批量里的移动**不享受**悬停免费，按批次额度算。

## 8. 出错先看状态

`hands_status` 一条命令回答：有没有授权、授权到几点、剩几次、频率用了多少、人类是否在操作、
后端是否可用、**热键有没有被别的程序占用**、最近几条审计。加 `doctor: true` 追加引擎自检。
