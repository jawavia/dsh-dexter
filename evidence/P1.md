# P1 — Bundle skeleton: one config, one audit, one stop bus

**Goal (order §5 P1):** a new `dsh-dexter` bundle with a single config schema, a single
settings surface, a single audit writer and a StopBus skeleton.

## Delivered

| File | What it is |
|---|---|
| `package.json` | bundle manifest: `dsh.bundle.patch`, `os: ["win32"]`, `exports` for locale + icon, `files` covering every runtime module |
| `cordis.patch.yml` | one `insert` row (`id: dsh-dexter`), empty config on purpose |
| `index.js` | `apply(ctx, config)`: normalizes config, builds audit/gate/StopBus/human detector/backends/kernel, registers the tools and the `/dexter` command, logs one readiness line |
| `kernel/config.js` | **the only** declaration of every configuration key (`FIELD_SPEC`) plus the derived `DEFAULTS`, schemastery `Config` and `normalizeConfig` |
| `kernel/audit.js` | one writer: `<data>/audit/hands.jsonl`, append-only, `seq/prev/h` chain, rotation with retention |
| `kernel/gate.js` | one authorization gate (per-action ask → bounded grant → latched), stop = revoke |
| `kernel/stopbus.js` | Esc / Ctrl+Alt+F11 (hard) / Ctrl+Shift+F11 (soft) / `stop.signal` file, plus **Ctrl+Alt+F12 → bounded grant** (the human's only grant path besides `/dexter arm`) |
| `kernel/human.js` | human-activity suspension shared by every backend |
| `locale/en.json`, `locale/zh.json`, `icon.svg`, `docs/DETAIL.md` | display metadata (Plugin Manager row + detail page) |

## Measured

- `apply()` with a stand-in host registers 4 tools and logs
  `ready: 4 tools [hands_view, hands_act, hands_run, hands_status] · mode=per-action …`
  (from `baseline/local/dexter-surface.json`).
- The bundle resolves in a bare `node` run (`apply` never imports the host's packages
  except an optional schemastery import that degrades to `undefined`).
- `test/03-config-single-source.test.mjs`: **12/12** — schema defaults equal runtime
  defaults, unknown keys dropped, out-of-range values clamped, latched without both
  bounds falls back to per-action, no code path reads `config-overrides.json`.
- `tools/check-repo.mjs`: manifest/patch/locale/icon/files checks pass (**0 FAIL**).

## Deviations recorded

- **D1** (no custom web settings section; the plugin config page is the single
  settings surface).
- **D2** (legacy engines loaded from disk instead of vendored).

## Not done here

- No client (web) bundle: nothing in this plugin draws UI. `hands_status` and
  `/dexter status` carry the runtime state a panel would show.
